# 语文作文批改提升 Workflow

本文件定义语文作文批改的独立流程，不套用通用的「智能辅导六步法」。

---

## 前置条件

进入作文批改流程前，必须满足以下条件：

1. **作文文本已获取**：通过 OCR 识别或用户手动输入获得完整的作文文本
2. **内容完整性**：标题和正文内容完整，无明显缺失
3. **图片引用记录**：`source_path` 已正确记录（如有），方便回溯查看手写原稿

### 输入数据格式

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| `essay_scope` | **题型：`micro`（微写作，10分）/ `major`（大作文，50分）** | 是 |
| `title` | 作文标题 | 是 |
| `paragraphs` | 段落内容数组 | 是 |
| `word_count` | 字数统计 | 是 |
| `essay_type` | 作文类型（argumentation/narration/application） | 是 |
| `source_path` | 图片存储路径（如有） | 否 |

> 若无法从题目要求或字数判断 `essay_scope`，**先向用户确认是微写作还是大作文**，不要默认按大作文评分。

---

## 一、评分标准（北京卷）

北京卷语文写作分为**两道独立的题**，满分与要求各不相同，**必须先判定属于哪一种，再套用对应的评分表**：

| 题型 | `essay_scope` | 满分 | 字数要求 |
|------|---------------|------|----------|
| **微写作** | `micro` | **10 分** | 不超过 150 字 |
| **大作文** | `major` | **50 分** | 不少于 700 字 |

> 两题合计 60 分。**严禁把两者的分数混在一起给出「总分」**，也不得用大作文的评分表去评微写作。

### 1. 微写作（满分 10 分）

微写作按**四条标准**综合判定档位，不做维度分拆打分。

**一类文（8-10 分）四条标准**：

| # | 标准 | 含义 |
|---|------|------|
| 1 | **审题精准** | 紧扣题干限定的话题范围，不越界、不偏移 |
| 2 | **观点鲜明** | 立场明确，**不骑墙**、不模棱两可 |
| 3 | **理由充分且多角度** | 支撑理由不止一条，且从不同角度切入 |
| 4 | **认识有深度** | 不停留在表层复述，有进一步的分析与思考 |

**对比锚点（5 分文）**：**理由单一、表述重复**——只有一条理由且反复换说法陈述，即落到 5 分档。

> 判分时先逐条比对上述四标准，命中越多档位越高；若出现「理由单一 + 表述重复」的特征，直接向 5 分档靠拢。

### 2. 大作文（满分 50 分）

大作文由**基础等级 + 发展等级**两部分构成，合计 50 分：

| 等级 | 满分 | 评分要点 |
|------|------|----------|
| **基础等级** | **40 分** | 立意精准，紧扣材料内核，中心贯穿全文；结构完整严谨，层次递进清晰；文体特征鲜明，符合议论文／记叙文硬性规范；内容充实，素材贴合主题；语言凝练流畅，句式丰富，无病句错别字 |
| **发展等级** | **10 分** | **议论文**：具备深度思辨，辩证剖析二元关系。**记叙文**：细节鲜活、情感真挚。共通：兼具思想性与文学性，无模板套作痕迹，有独立思考与个性化表达 |

> 发展等级的评分要点**按文体分流**：议论文看思辨与辩证，记叙文看细节与情感。判分前先确定文体，再套用对应要点。

**档位特征**：

| 档位 | 分数 | 特征 |
|------|------|------|
| **一类文** | **42-50 分**（满分档） | 同时满足上表基础等级与发展等级的全部要点 |
| **二类文** | 未给定具体区间 | 立意正确，但**思辨薄弱、结构常规** |
| **三类文** | 未给定具体区间 | **立意偏差、内容空洞** |
| **四类文** | 未给定具体区间 | **偏离题意、字数不足**；考场极少出现 |

> [!IMPORTANT]
> **本节内容来源与边界：**
> - 以上评分结构均**来自用户提供的北京卷评分细则**：两题总分（10 / 50）、字数要求（≤150 字 / ≥700 字）、大作文「基础等级 40 + 发展等级 10」的拆分、一类文 42-50 分区间、微写作一类文四条标准与 5 分文对比锚点。
> - **仅一类文给出了明确分数区间。二类／三类／四类文只有定性特征，没有官方分数区间**——批改时**按定性特征判档并说明理由，不要编造具体分数区间**；确需给出分数时，只给该档内的估分并注明是估分。
> - 若用户后续提供更完整或更新的细则（如各档的准确区间），**一律以用户提供的为准**。

### 3. 字数检查

- **微写作超过 150 字**或**大作文不足 700 字**时，先在批改结果中明确提示字数问题及其扣分影响，再进行分项评分。
- 大作文**字数不足**是四类文的判定特征之一；字数严重不足时，提示学生补写完整后重新提交。

## 二、作文批改流程

### 1. 审题分析
- **题目解读**：分析题目要求、关键词、限制条件
- **立意判断**：判断学生立意是否准确、是否偏离题意
- **角度评估**：评估选择的写作角度是否新颖、深刻

### 2. 分项评分
- **先确认 `essay_scope`**，再套用对应评分方式：
  - **大作文（major）**：分别给出**基础等级（/40）**与**发展等级（/10）**得分；发展等级按文体分流——议论文看深度思辨与二元辩证，记叙文看细节与情感。
  - **微写作（micro）**：不做维度分拆，按「审题精准 / 观点鲜明 / 理由充分且多角度 / 认识有深度」四条标准逐条比对，综合判档。
- 给出得分与满分（如 `43 / 50`、`9 / 10`），**不得只给裸分**，并给出档位（一类文/二类文/三类文/四类文）
- **仅一类文有官方分数区间（大作文 42-50、微写作 8-10）**；判为二类及以下时，以定性特征说明理由，给分注明为估分
- 标注扣分点和理由

### 3. 问题诊断
- **审题偏差**：是否偏离题意、关键词理解错误
- **结构问题**：开头结尾是否有力、段落逻辑是否清晰
- **语言问题**：表达是否流畅、用词是否准确、是否有病句
- **素材问题**：素材是否陈旧、运用是否恰当、论据是否充分
- **论证问题**：论证是否单一、逻辑是否严密、是否有说服力

### 4. 升格建议
- **针对性修改**：针对每个问题给出具体的修改建议
- **段落重写**：挑选关键段落进行示范改写
- **素材替换**：推荐更合适的素材或事例
- **结构优化**：建议调整文章结构和段落顺序

### 5. 范文对照
- **范文选择**：从 `subjects/语文/` 中查找同题或同类题目的 `model_essay`（作文范文）和 `classmate_essay`（同学范文）
- **对比分析**：对比学生作文与范文的差距，分析范文的优点
- **借鉴建议**：建议学生借鉴范文的哪些方面

### 6. 片段练习
- **针对性练习**：针对薄弱点生成 1-2 个片段写作练习
- **审题练习**：给出类似题目进行审题训练
- **素材积累**：推荐相关素材和事例供学生积累

## 三、作文文件 Frontmatter 模板

```yaml
---
date: YYYY-MM-DD
subject: 语文
topic: 作文
reference_type:  # 空或 standard_answer/model_essay/classmate_essay
essay_scope: major  # micro（微写作，满分10）/ major（大作文，满分50）
essay_type: argumentation  # argumentation（议论文）/ narration（记叙文）/ application（应用文）
title: [作文标题]
word_count: [字数]
source_path:  # OCR识别的原始图片路径，如 raw/YYYY/MM/photo.jpg
score: [得分]
full_score: 50  # micro 为 10，major 为 50；必须与 essay_scope 一致
score_is_estimate: false  # 判为二类及以下（无官方区间）时置 true
grading:  # 按 essay_scope 二选一
  # essay_scope: major（大作文）
  basic: [基础等级得分]/40      # 立意、结构、文体、内容、语言
  developmental: [发展等级得分]/10  # 议论文重思辨辩证；记叙文重细节情感
  # essay_scope: micro（微写作）时改用下面四条标准的达成情况：
  # criteria:
  #   审题精准: [达成/部分达成/未达成]
  #   观点鲜明: [达成/部分达成/未达成]
  #   理由充分且多角度: [达成/部分达成/未达成]
  #   认识有深度: [达成/部分达成/未达成]
grade_level: [一类文/二类文/三类文/四类文]
weak_points:
  - [薄弱点1]
  - [薄弱点2]
---
```

## 四、与 _index.md 的集成规则

### 作文薄弱点记录
语文 `_index.md` 的薄弱点表中，作文相关薄弱点按以下维度记录：

| 知识点 | 错误次数 | 最近错误日期 | 状态 |
|--------|----------|--------------|------|
| 审题偏差 | [N] | [YYYY-MM-DD] | ⚠️ 待巩固 |
| 素材陈旧 | [N] | [YYYY-MM-DD] | ⚠️ 待巩固 |
| 论证单一 | [N] | [YYYY-MM-DD] | ⚠️ 待巩固 |
| 语言平淡 | [N] | [YYYY-MM-DD] | ✅ 已掌握 |

### 更新时机
- **每次作文批改后**：更新语文 `_index.md` 的薄弱点表（新增或更新作文相关薄弱点）
- **每次作文复习后**：连续 3 次同类问题改善，状态从 ⚠️ 待巩固 改为 ✅ 已掌握

## 五、范文对照机制

### 范文来源
1. **model_essay（作文范文）**：老师提供的满分作文、优秀范文
2. **classmate_essay（同学范文）**：同学的高分作文

### 范文使用
- 批改时主动检索同题或同类题目的范文
- 在「范文对照」环节对比分析学生作文与范文的差距
- 推荐学生借鉴范文的优点

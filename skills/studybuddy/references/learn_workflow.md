# 知识点学习工作流（learn_workflow）

本文件定义通用知识点学习与巩固的处理流程，支持多种学习场景。

---

## 一、适用场景

- **知识点学习**：用户主动学习某个知识点
- **薄弱点复习**：针对历史薄弱点进行专项复习
- **概念理解**：深入理解某个学科概念
- **公式推导**：学习数学/物理公式的推导过程
- **实验原理**：学习化学/生物实验的原理和操作

> 古诗词、文言文学习走 `classical` 子命令，不在此流程内。

---

## 二、处理流程

### 1. 学习需求识别

**输入类型识别**：
- **明确知识点**：用户指定要学习的知识点（如"学习导数的应用"）
- **薄弱点复习**：用户请求复习薄弱点（如"复习我的薄弱点"）
- **概念理解**：用户请求理解某个概念（如"什么是牛顿第二定律"）

**内容类型识别**：
- **普通知识点**：数学公式、物理定律、化学方程式、生物概念等
- **实验内容**：实验原理、操作步骤、数据处理等

**路由逻辑**：
```
用户输入
    │
    ├── 明确知识点/概念理解 → 执行通用学习流程
    │
    └── 薄弱点复习 → 读取 _index.md 薄弱点 → 执行通用学习流程
```

> 若识别为古诗文学习，提示用户使用 `classical` 子命令；不在本流程内处理。

**未支持学科处理**：本技能仅支持六科（语文、数学、英语、物理、化学、生物）。识别学习需求所属学科后，若为未支持学科，简单跳过即可，不进行学习处理；用户询问时，可告知不支持该学科。

### 2. 学情数据读取

**读取内容**：
- **profile.md**：学生基础信息、教材版本、学习偏好
- **_index.md**：薄弱点表、正确率趋势、最近错题、导入资料索引
- **subjects/<学科>/YYYY/MM/**：相关错题记录和导入资料
- **导入资料检索**：按学科检索 `subjects/<学科>/YYYY/MM/` 下已导入的学习资料，通过主文件了解资料结构和知识点覆盖，按章节子文件直接提取相关内容，必要时通过引用链接寻找 raw 文件

**个性化调整**：
- 根据学生年级和教材版本调整讲解深度
- 根据薄弱点状态调整复习重点
- 根据学习偏好调整讲解方式

### 3. 视频推荐

在进行详细知识点讲解前，先搜寻并推荐 1-2 个国内平台的优质概念/方法类微课视频，或提供高精确度搜索关键词，帮助学生快速建立背景理论框架。

> [!NOTE]
> **术语说明**：「联网搜索工具」指 agent 运行环境提供的实时联网检索能力（如 QoderWork、WorkBuddy、Trae Work 等平台各自提供的联网搜索工具，具体名称可能不同）。若环境未提供该能力或联网失败，一律走下方降级策略。

#### 3.1 硬性要求

**每次错题辅导/知识点学习，必须执行视频推荐：**

1. **若环境提供联网搜索工具时**：优先锁定 **B站（第一个推荐平台）** 搜索相关知识点讲解视频（检索词加入 `bilibili` 或使用 `site:bilibili.com`），并**必须给出 1-2 个具体的视频页链接**（`https://www.bilibili.com/video/BVxxxx`，附标题、时长、推荐理由）。**禁止仅提供 B站搜索页链接来代替具体视频**——只有完全无法获取到具体视频链接（无搜索工具 / 无任何结果）时才允许走降级策略。
2. **无联网搜索工具或联网失败时（降级策略）**：提供搜索关键词，引导用户在 B站/国家中小学智慧教育平台/北京中小学智慧教育平台自行搜索

如未推荐视频或未给搜索关键词，视为讲解流程不完整。

#### 3.2 高中选片原则

- **高考导向**：优先推荐标注「高考」「一轮复习」「二轮复习」的视频，贴近考试要求
- **真题优先**：含高考真题讲解的视频优先于纯概念讲解
- **效率至上**：高中生时间紧，优先 5-20 分钟的精讲视频，超过 30 分钟需在推荐理由中说明必要性
- **难点聚焦**：针对薄弱点推荐专题突破视频，避免泛泛而谈的综合课

#### 3.3 推荐视频平台

**1. B站（bilibili）** — 首选平台，免费、内容丰富、UP主专业，全学科适用。
- **推荐UP主**（按学科，结果筛选时优先命中）：
  - 语文：国家玮的语文日常、高盛元、高考语文杨洋、中文系五匪子、朴鲤朴鲤、戴建业老师、吴小轶语文教研室
  - 数学：3Blue1Brown、赵礼显老师、北大数学胡源老师、马同学图解数学、阿不高中数学、橘子zhen好吃、数之形
  - 英语：英语的平行世界、高中英语U学
  - 物理：李永乐老师官方、HuangFuRen、一物儿、夏梦迪-高考物理、一只不像老师的小怀怀、坤哥物理
  - 化学：化学老师李政、小球老师讲化学、一化儿、陈筱化学、氟Cl双醛
  - 生物：见医知二、李林生物、一生儿、高中生物莫西老师、金晶生物、锦城大同教育
- **视频格式**：视频链接可直接在浏览器打开播放

**2. 国家中小学智慧教育平台** — 免费、官方权威、无广告，教育部主管，网址：https://basic.smartedu.cn/syncClassroom/auto

**3. 北京中小学智慧教育平台（北京市空中课堂）** — 免费、地方权威，北京市教委主管，网址：https://basic.beijing.smartedu.cn

#### 3.4 B站检索式与选择算法

**通用 B站检索式**（有联网搜索工具时优先使用）：

```
"[知识点] 高中[学科] 讲解 site:bilibili.com"
"[知识点] 高考 一轮复习 bilibili"
"[知识点] 高中[学科] 真题 讲解 bilibili"
```

**B站必遵的选择算法**（按以下顺序产出 1-2 个**具体视频链接**）：

1. **检索**：用上述通用检索式（可追加头部 UP主名提高命中）搜索，得到一组候选视频。
2. **优先推荐 UP主**：从候选中筛选 UP主属于上方「推荐UP主」列表的视频，优先挑选 1-2 个（须满足高中选片原则）。
3. **择优兜底**：若候选中**没有**来自推荐 UP主 的视频，则按高中选片原则从其余结果中择优挑选 1-2 个。
4. **提取具体链接**：对每个选定视频，提取其 B站视频页链接 `https://www.bilibili.com/video/BVxxxx`（**不是搜索页链接**），连同标题、时长、推荐理由一并给出。

> 检索式层面（可选增强）：在 query 中追加学科对应的头部 UP主名可更精准命中，例如：
> ```
> "[知识点] site:bilibili.com 赵礼显老师"   # 数学
> "[知识点] site:bilibili.com 李永乐老师官方" # 物理
> "[知识点] site:bilibili.com 化学老师李政"   # 化学
> ```

### 4. 知识点讲解与交互确认

**讲解流程**：
1. **概念引入**：用生活实例或类比引入知识点
2. **核心定义**：给出准确的定义和公式
3. **原理推导**：讲解公式/定理的推导过程
4. **例题演示**：通过例题演示应用方法
5. **易错点提醒**：指出常见错误和注意事项

**可视化讲解**：
- 使用图形、图表辅助理解
- 使用 ASCII 图表或 Markdown 表格
- 几何题用示意图、物理题用受力分析图、化学题用反应机理图

> [!IMPORTANT]
> **交互式断点**：知识点讲解完成后，**必须暂停并询问学生是否完全搞懂该知识点，或是否需要调整讲解角度/难度**。在学生未确认理解或主动要求前，禁止在对话中显式输出巩固练习（下方「5. 练习巩固」）。

### 5. 练习巩固

**练习生成**：
- 根据知识点生成梯度练习题
- 基础巩固 → 提高强化 → 挑战拔高
- 单次不超过 8 题

**练习形式**：
- **选择题**：检验概念理解
- **填空题**：检验公式记忆
- **解答题**：检验应用能力

### 6. 学习效果评估

**评估方式**：
- **即时反馈**：练习完成后立即批改并给出解析
- **正确率统计**：统计本次练习的正确率
- **薄弱点更新**：根据练习结果更新薄弱点状态

**状态更新**：
- 连续 3 次答对 → 标记为 ✅ 已掌握
- 错误率较高 → 标记为 ⚠️ 待巩固
- 超过 30 天未复习 → 标记为 ⚠️ 待巩固

### 7. 学习记录归档

**归档内容**：
- **学习内容**：知识点名称、讲解摘要
- **练习记录**：题目内容、答案、正确率
- **视频推荐**：推荐的视频链接

**归档位置**：
- `subjects/<学科>/YYYY/MM/<YYYY-MM-DD>-<topic-slug>-learning.md`

**Frontmatter 模板**：
```yaml
---
date: YYYY-MM-DD
subject: [学科]
topic: [知识点]
learning_type: [学习类型]
correct_rate: [正确率]
status: learned  # learned/reviewing/weak
videos:
  - [视频标题]: [视频链接]
---
```

## 三、学习策略

### 1. 循序渐进策略

**学习顺序**：
1. **基础概念**：理解基本定义和公式
2. **简单应用**：通过简单例题掌握基本方法
3. **综合应用**：解决综合性问题
4. **拓展延伸**：探索知识点的深层含义和应用

### 2. 间隔重复策略

**复习周期**：
- 第 1 次学习后：1 天复习
- 第 2 次复习后：3 天复习
- 第 3 次复习后：7 天复习
- 第 4 次复习后：14 天复习

**复习方式**：
- 快速回顾核心概念
- 做 2-3 道练习题检验记忆

### 3. 错题驱动策略

**学习路径**：
1. **识别薄弱点**：从 `_index.md` 获取薄弱点列表
2. **针对性学习**：针对薄弱点进行专项学习
3. **练习巩固**：生成针对性练习题
4. **评估效果**：检查正确率是否提升

### 4. 操作概要记入 log 文件

每次执行知识点学习或复习流程后，必须将操作概要记入 `output/YYYY/MM/YYYY-MM-DD-log.md` 文件：

**记录内容**：
- **操作类型**：知识点学习/薄弱点复习/概念理解/间隔复习
- **学习内容**：学习的知识点名称、讲解摘要
- **学习时长**：本次学习/复习耗时（分钟）
- **练习记录**：生成的练习题数量、正确率
- **复习轮次**：若为间隔重复复习，记录当前复习轮次（第 1/2/3/4 次）
- **视频推荐**：推荐的视频链接
- **更新的索引**：更新的 `_index.md` 文件及其内容摘要

**记录格式**：
```markdown
## 操作记录

### YYYY-MM-DD HH:MM:SS
- **操作类型**：知识点学习
- **学习内容**：导数的应用
- **学习时长**：45 分钟
- **练习记录**：生成5题，正确率80%
- **视频推荐**：[导数应用专题讲解](链接)
- **更新索引**：subjects/数学/_index.md（更新薄弱点状态）
```

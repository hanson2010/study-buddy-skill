# 报告文件模板

本文件定义学情报告文件的 Frontmatter 模板和正文模板。

---

## 1. 报告文件 Frontmatter 模板

```yaml
---
date: YYYY-MM-DD
report_type: daily  # daily/weekly/monthly/special
report_subtype:  # 专项报告时填写：weak_points/exam_compare/subject_analysis
title: [报告标题]
student_name: [学生姓名]
grade: [年级]
analysis_period:
  start_date: [YYYY-MM-DD]
  end_date: [YYYY-MM-DD]
summary:
  total_questions: [总题数]
  correct_rate: [正确率]
  weak_points_count: [薄弱点数量]
  study_days: [学习天数]
  study_hours: [学习时长(小时)]
---
```

## 2. 报告正文模板

### 日报正文示例

日报聚焦「今日待办」，内容最简化，语气轻松有趣，降低挫败感：

```markdown
# StudyBuddy 小叮咛（2026年7月27日）

## 一、昨日回顾
（如果昨天没有任何活动则跳过此节）
- 数学：函数与导数错了 2 道，正确率 60%，需要加把劲！
- 物理：电磁感应做得不错，正确率 80%，继续保持～

## 二、今日待办
- [ ] 数学：函数与导数练习题 5 道（薄弱点巩固）
- [ ] 物理：电磁感应错题重做
- [ ] 语文：作文审题训练 1 篇

## 三、今日能量补给
> 今天也是充满希望的一天！做完这三项，你就是自己的小英雄 🚀
```

### 周报正文示例

周报聚焦「本周回顾 + 下周展望」，保持简短，便于快速浏览：

```markdown
# StudyBuddy 学情周报（2026年7月6日 ~ 2026年7月12日）

## 一、本周回顾
- 学习 5 天，共 12 小时；批改 45 题，平均正确率 78%（环比 +3%）
- 数学、物理正确率上升，语文持平，化学略降
- 新增薄弱点：数学·立体几何（⚠️ 待巩固）；改进：物理·电磁感应（✅ 已掌握）
- 主要错误类型：概念不清（25%）、计算失误（19%）

## 二、薄弱点速览
- **数学·函数与导数**：本周错了 4 道，需要重点攻克！
- **物理·电磁感应**：楞次定律还需要再巩固一下
- **语文·作文审题**：审题技巧有待加强，你已经进步很多了！

## 三、下周展望
- 重点复习：数学（函数与导数、立体几何）、物理（电磁感应巩固）
- 建议：数学每天 30 分钟薄弱点专项；语文每周 1-2 篇作文审题训练
- 推荐视频：[函数与导数专题讲解](链接)、[立体几何空间想象训练](链接)
```
